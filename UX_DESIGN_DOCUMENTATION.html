1. Project Overview

🎯 Purpose

A free, serverless, read-only inventory dashboard for viewing current inventory with photos. Built for warehouse/facility staff who need quick visual access to stock levels, categories, and expiry tracking.

🏗️ Architecture

  • Frontend: React 18 + Vite + TypeScript
  • Styling: Tailwind CSS (CDN)
  • Hosting: Cloudflare Pages (static + Functions)
  • Database: Turso (libSQL, 5GB free)
  • Images: Tigris Data (S3-compatible, 5GB free)
  • Cost: $0/month

🔑 Key Features

  • Real-time inventory table with pagination
  • Search, filter by category/status/view
  • Statistics cards (total, low stock, out of stock, expiring, est. value)
  • Photo thumbnails from Tigris
  • CSV export with current filters
  • Responsive (mobile → desktop)

🚫 Non-Goals (MVP)

  • No authentication (public read-only)
  • No write/edit/delete operations
  • No user accounts or roles
  • No Excel export (CSV only)
  • No real-time websocket updates

2. Home Page — First Load Experience

🎬 Initial Load Sequence

1. User navigates to https://inventory-dashboard.pages.dev
⬇
2. Cloudflare Pages serves index.html + dist/assets/* (cached at edge)
⬇
3. React app mounts → App.tsx renders header + loading spinner (Loading.tsx)
⬇
4. useEffect triggers fetchInventory() → GET /api/inventory?page=1&limit=25
⬇
5. Pages Function functions/api/inventory.ts executes:
  • Connects to Turso via @libsql/client (HTTP)
  • Runs parameterized query with filters/pagination
  • Returns { items, pagination, stats }
⬇
6. Response received → setData(json) → Loading hides → Dashboard renders
⬇
7. Parallel fetch: GET /api/stats for fresh stat cards (optional optimization)

5. Component Breakdown

📱 App.tsx (Root)

  • State: filters, data, loading
  • Effect: fetchInventory on filter change
  • Renders: Header, StatsCards, Filters, ExportButton, InventoryTable
  • Passes: callbacks for page/limit changes

📊 StatsCards.tsx

  • Props: stats object
  • 5 cards: Total, Low Stock, Out of Stock, Expiring, Est. Value
  • Icons + color-coded badges
  • Responsive grid (1/2/5 columns)

🔍 Filters.tsx

  • Props: filters, onChange, onReset
  • Search input (debounced)
  • 3 dropdowns: category, status, view
  • Reset button
  • Mobile: collapsible

📥 ExportButton.tsx

  • Props: filters
  • Constructs export URL with current filters
  • Anchor tag → native browser download
  • Supports format=csv (excel = 501)

📋 InventoryTable.tsx

  • Props: items, pagination, onPageChange, onLimitChange
  • Desktop: HTML table with sortable headers
  • Mobile: Card layout per row
  • Photo thumbnails (50×50)
  • Status badges with color coding
  • Days-left calculation

⏳ Loading.tsx

  • Animated spinner + "Loading inventory..."
  • Full-screen overlay
  • Accessible: aria-live="polite"

7. Data Model

7.1 Turso Table: inventory_items

CREATE TABLE inventory_items (
  id TEXT PRIMARY KEY,           -- UUID
  name TEXT NOT NULL,
  sku TEXT UNIQUE NOT NULL,
  category TEXT NOT NULL,
  location TEXT,
  quantity INTEGER NOT NULL DEFAULT 0,
  min_quantity INTEGER NOT NULL DEFAULT 0,
  unit_cost REAL NOT NULL DEFAULT 0,
  expiry_date TEXT,              -- ISO date: YYYY-MM-DD
  photo_key TEXT,                -- Tigris object key
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX idx_inventory_category ON inventory_items(category);
CREATE INDEX idx_inventory_status ON inventory_items(
  CASE
    WHEN quantity = 0 THEN 'out_of_stock'
    WHEN quantity <= min_quantity THEN 'low_stock'
    ELSE 'in_stock'
  END
);
CREATE INDEX idx_inventory_expiry ON inventory_items(expiry_date);
CREATE INDEX idx_inventory_search ON inventory_items(name, sku, location);

8.4 Key Implementation Details

🔧 Turso Connection (functions/api/inventory.ts)

import { createClient } from '@libsql/client';

const db = createClient({
  url: env.TURSO_DATABASE_URL,
  authToken: env.TURSO_AUTH_TOKEN
});

// Parameterized query (prevents injection)
const result = await db.execute({
  sql: `SELECT * FROM inventory_items WHERE ... LIMIT ? OFFSET ?`,
  args: [limit, offset]
});

8.5 Common Tasks for Hermes

➕ Add New Filter Field

  1. Add to filters state in App.tsx
  2. Add input in Filters.tsx
  3. Pass through fetchInventory params
  4. Update functions/api/inventory.ts WHERE clause
  5. Add to ExportButton.tsx URL construction
  6. Add column to InventoryTable.tsx if display needed

🎨 Change Color Scheme

  1. Update tailwind.config in index.html
  2. Update badge colors in InventoryTable.tsx (status, days-left)
  3. Update stat card icon backgrounds in StatsCards.tsx

📊 Add New Stat Card

  1. Add aggregation query in functions/api/stats.ts
  2. Add to StatsCards.tsx component
  3. Add icon + color scheme

🔐 Enable Authentication

  1. Set SHARED_SECRET in Cloudflare Pages env vars
  2. Middleware functions/_middleware.ts auto-enables
  3. Clients must send X-API-Key: secret header
  4. For browser: use Cloudflare Access instead (OIDC/SSO)

8.7 Known Limitations / Future Work

  • No sort in MVP: Sort column click handlers exist in UI but API doesn't implement sort/order params yet
  • No Excel export: Returns 501; would need exceljs bundled in function
  • No image upload: Read-only; upload would need signed URLs + separate admin UI
  • No real-time: Polling or manual refresh only
  • Category list static: Should fetch DISTINCT category from DB
  • No facility scoping: FACILITY_ID env var exists but not wired to queries

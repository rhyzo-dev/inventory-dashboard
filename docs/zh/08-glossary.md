# 08 · 术语表(中文)

> 交付文档包 · [总目录](../README.md)。英文: [Glossary](../en/08-glossary.md)。

| 术语 | 含义 |
|------|------|
| **SKU** | 库存编码,是*目录/品类*层面的标识。**不唯一**:一个 SKU 可对应多个批次。 |
| **批次(Lot)** | 某 SKU 的一个实物批,由货位、生产/到期日期、规格共同标识。一条 `consumable_item` 记录就是一个批次。 |
| **货位(Bin)** | 批次实物存放的位置(货架、料笼、仓库区)。 |
| **FEFO** | *First-Expired, First-Out*,先到期先发放。 |
| **即将到期** | 30 天内到期(仅指未来日期)。 |
| **已过期** | 到期日已过。与"即将到期"区分开。 |
| **最小/最大阈值** | 可选的每-SKU(或每批次)低库存上下限,决定"偏低/缺货"状态。 |
| **批次键(Lot key)** | 用于去重与导入的六字段标识:SKU + 名称 + 货位 + 规格 + 生产日期 + 到期日期。 |
| **试运行(Dry run)** | 导入预览,汇报"将会发生什么"但不真正写入。 |
| **D1** | Cloudflare 的托管 SQLite 数据库。 |
| **Tigris** | S3 兼容的对象存储(存放物料照片)。 |
| **JWT** | 会话令牌(访问令牌 8 小时 + 存储的刷新令牌 7 天)。 |

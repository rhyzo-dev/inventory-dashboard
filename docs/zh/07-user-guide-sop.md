# 07 · 用户手册 / SOP(中文)

> 交付文档包 · [总目录](../README.md)。给工厂日常操作人员用。英文: [User Guide / SOP](../en/07-user-guide-sop.md)。术语表: [08](./08-glossary.md)

## 1. 登录
1. 打开系统网址,输入账号和密码。
2. 首次使用:由管理员为你创建账号;(公开演示环境可用演示账号 `demo` / `Demo@2026!`)。
3. 忘记密码:请管理员在「用户」面板中重置。

**权限:** `viewer`(查看)可只读;`editor`(编辑)可新增/修改物料、类别、单位;`admin`(管理员)另可删除、管理用户、设置阈值。

## 2. 看看板
- 顶部**统计卡片**是快速计数:**全部 / 偏低 / 缺货 / 即将到期 / 已过期**。点某张卡片可把列表过滤成那一组。
- **已过期(红)**= 过期日期已过 —— 按规程停用并处理。
- **即将到期(黄)**= 30 天内到期 —— 计划优先使用。
- 「到期」列会显示日期加彩色提示:红色「已过期 · −Nd」、黄色「+Nd · 即将到期」、其余为绿色。

## 3. 新增物料
### 单条新增
1. 点右上角 **Add Item**。填 SKU、名称、数量、单位、货位(bin)、类别、规格、生产日期、到期日期。
2. **重复提示:** 如果你重新录入一个已存在的批次(SKU + 名称 + 货位 + 规格 + 生产日期 + 到期日期 六项都相同),表单会列出相同比次的提示。必须勾选 **“Add anyway(仍然添加)”** 才能保存;否则会被阻止。真正的新批次(任一项不同)可正常保存。

### 批量导入
1. **Import Items** → **Download template**(模板,`.xlsx` 或 `.csv`)。
2. 填写 **Rows** 工作表:`sku` 必填,其余列选填;填得越全,去重越准。
3. 上传文件。系统先显示**预览**(将新增多少条、因重复会跳过多少条),确认后再提交。
4. **重复的会被跳过并汇报,绝不会被覆盖。** 所以重复上传同一份文件是安全的,不会产生重复批次。

## 4. 类别与单位
可在面板中自建**类别**和**单位**(编辑及以上权限)。新建的类别会自动出现在筛选下拉里。有物料还在用时,无法删除该类别/单位 —— 先把相关物料改到其他名称。

## 5. 按 SKU 视图(FEFO)与阈值
- **By-SKU(FEFO)** 标签:按 SKU 汇总各批次在库总量、批次数、最早到期日,并给出**发放顺序**(先到期先发放)。
- **阈值:** 大多数 SKU 不需要。对周转快的物料,可在「阈值」里设每-SKU 的最小/最大值。没有阈值时则不显示。

## 6. 照片
把鼠标停在某行上,可**添加**或**删除**照片。图片安全存储,通过系统展示(非公开链接)。

## 7. 常见任务
| 我想… | 这样做 |
|-------|--------|
| 看哪些快到期 | 点「即将到期」卡片,或 View → Expiring Soon |
| 看哪些已坏/过期 | 点「已过期」卡片,或 View → Expired Only |
| 该先发哪一批 | 打开 By-SKU 视图,展开该行(FEFO 顺序) |
| 补货 | Add Item,或批量导入 |
| 导出清单 | Export → CSV / XLSX |

## 8. 故障排查
- **账号被锁** —— 连续输错密码;等 15 分钟或联系管理员。
- **改密时提示"该密码曾泄露"** —— 换一个更强的密码。
- **导入时跳过了部分行** —— 这是去重在起作用;看预览里具体跳过了哪些。
- **导入后没有物料** —— 确认填了 `sku` 列,并且点了"确认提交"。

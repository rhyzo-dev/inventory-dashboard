## 快速要点(详见手册)
- **导入模板日期格式:** `YYYY-MM-DD`(年‑月‑日)。`2025-01-01` = 2025 年 1 月 1 日;中间是**月份**,最后是**日期**,不是"年‑日‑月"。可留空。
- **重复批次:** 六项(SKU + 名称 + 货位 + 规格 + 生产日期 + 到期日期)完全相同才算重复;导入时重复项**跳过并汇报**,不会覆盖,可放心重复上传。
- **已过期(红)与即将到期(黄)** 是分开的两档;已过期表示到期日已过,应停用。
